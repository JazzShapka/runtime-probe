# Cowork cloud · 09.09.2026

Канал доставки: **плагин** из публичного git-маркетплейса. Проектный канал (`.claude/settings.json`)
недоступен конструктивно — сессия живёт в песочнице (`/root`, права root), рабочая папка туда не монтируется.

| Событие | Результат |
|---|---|
| `SessionStart` | 🔴 не эмитится — 0 срабатываний в трёх сессиях, включая старт сразу с команды |
| `UserPromptSubmit` | ✅ `additionalContext` доходит до модели |
| `PreToolUse` / `PostToolUse` | ✅ и на Bash, и на Agent |
| `Stop`, `SubagentStart`, `SubagentStop`, `Notification` | ✅ |
| `SessionEnd`, `PreCompact` | ⚪️ повода не возникло |
| `deny` | ✅ вызов реально заблокирован |
| `ask` | ✅ диалог Deny / Allow once показан пользователю |

**Особенности среды:** слэш-команды `/plugin` нет — плагин ставится другим путём; песочница под root;
лог зонда лёг в `/root/.hook-probe/`.

**Наблюдение о модели:** агент сообщил «подтверждение не запрашивалось», пока пользователю показывался
диалог `ask`, и достроил объяснение («auto-режим»). Модель не видит слой разрешений — UI-эффекты
подтверждает только человек.

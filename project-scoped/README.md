# Проба: доставка хуков через `.claude/settings.json` проекта

Второй канал доставки, независимый от плагина: хуки объявлены в настройках рабочей папки.
Проверяет, читает ли среда проектную обвязку вообще.

**Как запускать:** открыть в проверяемой среде **эту папку** как рабочую директорию
(иначе её `.claude/settings.json` не подхватится), затем прогнать сценарий из корневого
[README](../README.md) и посмотреть отчёт:

```
python3 report.py     # лог: ./logs/hook-probe.jsonl
```

Лог намеренно лежит рядом с пробой, а не в `~/.hook-probe/` — так результаты этого канала
не смешиваются с плагинным, и при одновременной работе обоих видно, кто что запустил.

**Известный результат:** Claude Desktop (режим Code) читает этот канал одновременно с плагином —
одно событие срабатывает дважды, по разу от каждого источника. Cowork этот канал не читает вовсе.
